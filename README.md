# 妄想貯金

衝動買いを我慢した金額を記録する、iPhone向けの個人用Webアプリ。
データは端末内(localStorage)のみに保存され、サーバー通信は行いません。

## 使い方(GitHub Pagesで公開する場合)

1. このフォルダをリポジトリのルート(または `docs/` フォルダ)に置く
2. GitHubリポジトリの **Settings → Pages** で公開元を指定する
   - ルート直下に置いた場合: Branch = `main`, Folder = `/ (root)`
   - `docs/` に置いた場合: Branch = `main`, Folder = `/docs`
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできるようになる
4. iPhoneのSafariでそのURLを開き、共有ボタン →「ホーム画面に追加」でアプリのように使える

## ファイル構成

```
mousou-chokin/
├── index.html      本体(単一ファイルで完結)
├── manifest.json    PWA設定(ホーム画面アイコン・スプラッシュ用)
├── sw.js            オフライン対応のService Worker
├── icons/           ホーム画面アイコン一式(180/192/512px, favicon)
└── README.md        このファイル
```

## 主な機能

- 我慢した金額の記録(頻出アイテムのワンタップ登録、カテゴリ分け、過去日時の指定)
- 記録の編集・削除(誤タップ防止の2段階確認つき)
- 累計貯金額を身近な買い物に換算して表示(候補プールからランダムに選ばれるので毎回少し変わる)
- 統計(週/月/全期間の合計、14日・30日・月別のグラフ切り替え、カテゴリ別内訳、我慢ランキング)
- JSONでのバックアップ書き出し・読み込み
- ライト/ダーク/システム追従のテーマ切り替え
- オフラインでも開けるService Worker対応

## データについて

- すべて端末のブラウザ内(localStorage)に保存されます。機種変更やブラウザのデータ削除で失われるため、
  統計タブの「バックアップ」からJSONを定期的に書き出しておくことを推奨します。
- 旧バージョン(`mousou-chokin-v1`)のデータがある場合は初回起動時に自動移行されます。

## ローカルでの動作確認

Service Workerは `file://` では正しく動作しないため、簡易サーバーを立てて確認してください。

```bash
cd mousou-chokin
python3 -m http.server 8080
# http://localhost:8080 を開く
```
